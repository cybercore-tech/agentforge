# Contributing to AgentForge

AgentForge uses permanent milestone IDs and a plan-first workflow.

Before implementation:

1. create or select a milestone;
2. write its plan;
3. mark the plan `Approved`;
4. commit the plan separately;
5. validate the plan checkpoint;
6. only then begin implementation.

Implementation and plan approval must remain separate commits.
Every milestone closes with exact evidence and a clean handoff.
