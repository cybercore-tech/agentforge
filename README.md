# AgentForge

AgentForge is a local-first, model-agnostic agentic software-development environment.

Its purpose is to turn software ideas into auditable engineering workflows built from explicit
plans, isolated Git worktrees, interchangeable coding agents, capability-scoped permissions,
deterministic quality gates, CI failure classification, structured handoffs, and permanent audit
history.

AgentForge treats AI models as replaceable workers. The durable system is the workflow, state,
permissions, evidence, and repository contract around them.

## Commands

- `forge` — operator-facing CLI and future TUI entry point.
- `forged` — background orchestration daemon.
